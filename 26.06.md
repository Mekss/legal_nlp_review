# The RQ List

## Bucket 1 — Explanatory / comparative → RAG answers these
**Status: working now (retrieval)**

Retrieve relevant passages → grounded, cited answer.

- *How good can we use AI models, with source references* → this **is** the tool
- *Precision (maybe not recall)* → the **evaluation** of the tool (recall isn't
  computable — can't enumerate the true relevant set)
- *Custody / contact — how courts frame them* → answered from RIS + ECHR
- *Why cases reach the highest court* → what they have **in common**
  (caveat: "why vs lower courts" needs a contrast corpus we don't have but there is supervised **cluster analysis**)
- *Extended family — how it's treated* → retrieved; presence-flag is cheap

→ Definitional, framing, and cross-jurisdiction questions: **answered + cited.**

## Bucket 2 — Metadata aggregates → computed directly
**Status: doable now, reliable (no NLP)**

Count over structured fields we already have — a `groupby`, not retrieval.

- *Cases vs population* → ECHR cases per country ÷ population data

Caveat (stated in thesis): measures **propensity to litigate at Strasbourg**,
not prevalence of the underlying issue.

→ The aggregate questions whose answer lives in metadata: **computed.**

---

## Bucket 3 — Content aggregates → honest abstention now
**Status: tool declines today; extraction = next phase**

Need a field **extracted from each case's prose**, then counted across the
whole corpus. Retrieval sees ~5 passages, not the corpus → it would *fabricate*
a count. Correct behaviour: **abstain.**

- *How many children with which parent (m/f)* → needs custody-outcome extraction
- *Married — does it make a difference* → extraction + small-N, descriptive only
- *Communication between parents vs child age* → fuzzy construct; hard / parked
- *Language / ethnicity* → mostly absent, unsafe to infer; narrow or park

Path forward: LLM-based structured extraction → **validated** table → `groupby`.


---

## What this demonstrates

- Explanatory/comparative → **answered with citations**
- Metadata aggregates → **can be computed/automated but rather for preselected set of questions, otherwise not feasible from text - needs structured data tables**
- Content aggregates → **honestly declined** (out of paradigm today)

**One finding already, surfaced through the tool:** ECHR frames alienation as a
*State enforcement-failure under Article 8*, not much as a psychological label.
